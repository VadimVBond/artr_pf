## 3. ⚠️ Известные ограничения (Technical Debt)
### 3.1. Критические (Требуют внимания)
Отсутствующие плагины:
js/plugins/isotope.pkgd.min.js — не найден, закомментирован
js/plugins/overscroll.min.js — не найден, закомментирован
Решение: Скачать файлы или удалить зависимость из кода
i18n не полностью интегрирован:
Атрибуты data-i18n расставлены только в шаблонах
Статический баннер требует ручной миграции
Решение: Добавить data-i18n во все текстовые узлы
### 3.2. Не критические (Плановые)
CSS дублирование:
Файлы color-*.css имеют одинаковую структуру
Решение: Перейти на CSS-переменные (:root)
Изображения без оптимизации:
Нет loading="lazy"
Нет srcset для адаптивности
Решение: Добавить атрибуты в шаблоны карточек
Доступность (A11y):
Отсутствуют aria-label для кнопок
Нет skip-link для навигации
Решение: Добавить ARIA-атрибуты в шаблоны
