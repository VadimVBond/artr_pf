
# Project Context
**Type**: HTML/CSS/JS Portfolios & Templates modernization.
**Goal**: Analyze, refactor, and upgrade to 2026 web standards.

## Project Structure
- **Multilingual Support**: The project contains several language versions:
  - `ru/`: Russian version
  - `en/`: English version
  - `uk/`: Ukrainian version
  - `de/`: German version
  - `fr/`: French version
- **Templates**: Includes various layouts like `onepage.html`, `blog-post.html`, `portfolio-single.html`, etc.
- **Assets**: CSS (SCSS), JS, and various media files in `css/`, `js/`, `img/`.

## Key Requirements
- Maintain semantic HTML5.
- Ensure high performance and SEO optimization.
- Smooth transitions and premium aesthetics.
