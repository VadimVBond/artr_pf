Этот план описывает создание комплексного мастер-промпта для аудита и улучшения AI-инфраструктуры проекта в директории `.ai/`.

## Цели
- Проверка консистентности всех компонентов в `.ai/`.
- Выявление устаревших или дублирующихся инструкций.
- Оптимизация взаимодействия между различными LLM (GPT, Claude, Qwen).
- Автоматизация процесса обновления документации и стратегий.
