# Walkthrough - Создание MASTER PROMPT

В рамках этой задачи был разработан и внедрен мастер-промпт для автоматизированного аудита и рефакторинга AI-инфраструктуры проекта.

## Что было сделано
1. **Анализ структуры**: Изучена директория `.ai/`, включая стратегии моделей, воркфлоу и текущие промпты.
2. **Разработка промпта**: Создан комплексный файл `MASTER PROMPT (проверка + рефактор всей ai структуры).md`, который позволяет любой LLM провести глубокий аудит системы.
3. **Синхронизация**: Все проектные документы (план, задачи, ворктру) скопированы в `.ai/docs/` согласно глобальным правилам.

## Основные компоненты MASTER PROMPT
- **Сбор контекста**: Инструкции по чтению всей директории `.ai/`.
- **Критерии проверки**: Консистентность моделей, актуальность путей, отсутствие дубликатов.
- **Шаблон отчета**: Структурированный вывод с ошибками, предупреждениями и планом действий.
